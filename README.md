# بصمة المعرفة — النسخة الأولية للموقع

واجهة عربية متجاوبة (RTL) لمنصة «بصمة المعرفة»، تضم صفحة رئيسية، ومسارات التعليم المهني والأكاديمي، وتحديًا تفاعليًا، وألعابًا تعليمية بسيطة، وأدلة إرشادية أولية، وقسم المجلة المرفقة مع القراءة والتنزيل وقراءة صوتية للنص التعريفي، ونموذج حساب محلي وشهادة إنجاز تجريبية قابلة للطباعة.

## التشغيل
- افتح `index.html` في متصفح حديث.
- للحصول على أفضل تجربة، شغّل مجلد المشروع عبر خادم محلي بسيط مثل Live Server في VS Code.
- لا يحتاج العرض الأساسي إلى تثبيت حزم.

## الملفات
- `assets/logo.png`: الشعار المرفق.
- `assets/magazine-issue-1.pdf`: ملف المجلة المرفق.
- `assets/magazine-cover.png`: صورة الغلاف المستخرجة من الصفحة الأولى للمجلة.

## حدود النسخة الحالية المهمة
هذه **نسخة واجهة أمامية تجريبية** وليست منصة إنتاجية آمنة بعد:
- الحسابات وكلمات المرور والنتائج تُحفظ في `localStorage` على الجهاز فقط، ولا تستخدمها مع بيانات حقيقية أو كلمات مرور حساسة.
- يلزم بناء Backend وقاعدة بيانات ومصادقة آمنة وصلاحيات إدارية قبل النشر العام.
- شهادة الإنجاز الحالية تجريبية وليست شهادة رسمية أو اعتمادًا حكوميًا.
- ميزة الاستماع تنطق نصًا تعريفيًا مختصرًا عن المجلة عبر إمكانات المتصفح؛ ليست تحويلًا صوتيًا كاملًا لنص صفحات PDF.
- روابط أجيال وسراج الرسمية لم تُدرج لأن التحقق من الرابط المعتمد مطلوب قبل النشر.
- الإحصاءات المعروضة تعريفية/محلية وليست إحصاءات حقيقية لمستخدمين فعليين.

## خطة التطوير للإنتاج
1. اعتماد تصميم المحتوى والمراجعة التحريرية للمجلة.
2. ربط Supabase أو Backend مماثل مع مصادقة آمنة وسياسات صلاحيات.
3. إنشاء لوحة إدارة حقيقية للمجلات والأسئلة والطلاب.
4. استخراج نص المجلة باستخدام OCR عند الحاجة، ومراجعته، ثم توليد صوت عربي كامل.
5. تخزين محاولات الاختبار على الخادم وإصدار شهادات بأرقام فريدة مع صفحة تحقق عامة.
6. إضافة اختبارات وصول وأمان وأداء قبل الإطلاق.
